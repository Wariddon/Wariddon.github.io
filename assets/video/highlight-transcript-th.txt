สวัสดีครับ ผม Wariddon Rattanamalee ผมทำ API ธนาคารและเครื่องมือสำหรับพนักงานตรวจออเดอร์ครับ

ที่ SCB ผมเป็นวิศวกรซอฟต์แวร์ นักพัฒนาฟูลสแตก ผมเขียน API ด้วย Spring Boot และช่วยย้ายระบบ SCB Connect ครับ

ที่ InblackM ผมทำงานพาร์ตไทม์ ดูแลหน้าตั้งราคาและตรวจออเดอร์ ก่อนส่งต่องาน ผมให้ระบบเช็กทั้งเจ้าของเดิมและสถานะของออเดอร์

ผมใช้ Claude กับ Codex ช่วยตามโค้ดและร่างเทสต์ แล้วอ่านส่วนที่แก้และทดสอบเอง ตัวอย่างงานดูต่อได้ในพอร์ตครับ
