ประสบการณ์ด้านซอฟต์แวร์ครอบคลุมธุรกิจประกันภัย โทรคมนาคม ธนาคาร และแพลตฟอร์มดิจิทัล เริ่มพัฒนาระบบตั้งแต่ปีสองพันสิบแปด ทั้งงานแบ็กเอนด์ เว็บแอปพลิเคชัน และระบบอัตโนมัติ โดยให้ความสำคัญกับความถูกต้องของข้อมูล และการเชื่อมต่อระหว่างระบบ

เริ่มต้นที่ไทยประกันภัย ในปีสองพันสิบแปด พัฒนาแอปพลิเคชันด้วย Java และ API สำหรับส่งข้อมูลกรมธรรม์ ดูแลการใช้ใบรับรองดิจิทัล และการเข้ารหัสข้อมูล รวมถึงระบบงานธุรกิจที่เชื่อมกับฐานข้อมูล

ที่ CAT Telecom พัฒนาระบบด้วย Java และ Spring Boot พร้อมช่วยทดสอบการทำงาน จากนั้นที่ TISCO ทำงานด้านการกำกับสิทธิ์ผู้ใช้ ด้วย Python และ Angular และมีส่วนพัฒนาระบบลายเซ็นดิจิทัลด้วย Java

งานหลักปัจจุบันคือ Backend Developer ที่ Extend IT Resource โดยทำงานให้กับธนาคาร SCB รับผิดชอบการพัฒนา API และเชื่อมต่อระบบธนาคาร รวมถึงปรับปรุงระบบ ช่วยทดสอบ และวิเคราะห์ปัญหา

ตัวอย่างงานคือการต่ออายุ token และหมุนเวียน connection pool ของ Azure Managed Redis รวมถึงปรับ gateway ให้ใช้ข้อมูลยืนยันตัวตนล่าสุดเมื่อต่อใหม่ อีกส่วนคือการส่งรายงาน ที่แยกกรณีมีไฟล์ ข้อมูลว่าง และการส่งไม่สำเร็จอย่างชัดเจน

อีกบทบาทที่ทำควบคู่กัน คืองานพาร์ตไทม์ที่ InblackM ในตำแหน่ง Senior Tech Development Consultant มีส่วนพัฒนาหน้าตรวจออเดอร์ การส่งต่องาน และระบบล็อกอินร่วมของเจ้าหน้าที่ รวมถึงระบบอัตโนมัติ และบริการ ERP ด้วยภาษา Go

ทั้งสองบทบาทใช้ Claude และ Codex ช่วยทำความเข้าใจโค้ด วิเคราะห์ปัญหา และร่างการแก้ไข จากนั้นตรวจโค้ด และทดสอบพฤติกรรมด้วยตัวเอง นอกจากนี้ยังพัฒนาผู้ช่วยในระบบแอดมิน แบบอ่านข้อมูลอย่างเดียว ที่ตรวจสอบหลักฐานอ้างอิง และยังค้นข้อมูลได้เมื่อ AI ไม่พร้อมใช้งาน

ประสบการณ์เหล่านี้ เชื่อมงานแบ็กเอนด์ ฟูลสแตก และการทำงานระหว่างระบบเข้าด้วยกัน โดยมีเป้าหมายร่วมกันคือข้อมูลที่ถูกต้อง ขั้นตอนทำงานที่ชัดเจน และการทำงานของแอปพลิเคชันที่เชื่อถือได้
