ผมเริ่มทำงานด้านซอฟต์แวร์มาตั้งแต่ปี 2018 ครับ

งานที่ทำมีทั้งแบ็กเอนด์ เว็บแอป แล้วก็ระบบอัตโนมัติ

ผ่านทั้งธุรกิจประกันภัย โทรคมนาคม ธนาคาร และแพลตฟอร์มดิจิทัล

ผมเน้นให้ข้อมูลถูกต้อง และระบบทำงานเชื่อมกันได้ครับ

เริ่มจากไทยประกันภัยครับ ผมพัฒนาระบบด้วย Java

แล้วก็ทำ API ส่งข้อมูลกรมธรรม์ไปยังหน่วยงานกำกับ

ในงานนี้ได้ดูทั้งใบรับรองดิจิทัล การเข้ารหัสข้อมูล

และระบบงานที่เชื่อมกับฐานข้อมูลหลายแบบครับ

ต่อมาที่ CAT Telecom ผมทำ Java กับ Spring Boot แล้วก็ช่วยทดสอบระบบครับ

ส่วนที่ TISCO ได้ทำระบบกำกับสิทธิ์ผู้ใช้ด้วย Python กับ Angular

และพัฒนาฟีเจอร์ในระบบลายเซ็นดิจิทัลด้วย Java ครับ

งานหลักตอนนี้ ผมทำแบ็กเอนด์ที่ธนาคาร SCB ครับ

พัฒนา API และเชื่อมต่อระบบธนาคาร

รวมถึงปรับปรุงระบบ ทดสอบ และช่วยหาสาเหตุปัญหาครับ

อย่างงาน Azure Managed Redis ผมทำส่วนต่ออายุ token และสลับ connection pool ครับ

แล้วก็ปรับ gateway ให้ใช้ข้อมูลยืนยันตัวตนล่าสุด เวลาเชื่อมต่อใหม่

อีกงานคือระบบส่งรายงาน

ซึ่งแยกให้ชัดว่า มีไฟล์ให้ส่ง ไม่มีข้อมูล หรือส่งไม่สำเร็จครับ

อีกบทบาทที่ทำควบคู่กัน คือเป็นที่ปรึกษาด้านพัฒนาระบบให้ InblackM แบบพาร์ตไทม์ครับ

ผมทำหน้าตรวจออเดอร์ ขั้นตอนส่งต่องาน และระบบล็อกอินร่วมของเจ้าหน้าที่

รวมถึงระบบอัตโนมัติ และงาน ERP ที่เขียนด้วย Go ครับ

ทั้งสองงาน ผมใช้ Claude กับ Codex ช่วยอ่านโค้ด หาปัญหา และร่างการแก้ไขครับ

จากนั้นตรวจโค้ดและทดสอบด้วยตัวเองอีกรอบ

ที่ InblackM ผมยังทำผู้ช่วยแอดมินแบบอ่านข้อมูล

มีหลักฐานอ้างอิง และมีระบบค้นหาสำรองครับ

ประสบการณ์ที่ผ่านมาทำให้ผมได้ทำทั้งแบ็กเอนด์ ฟูลสแตก และงานเชื่อมต่อระบบ

เวลาพัฒนางาน ผมจะดูทั้งความถูกต้องของข้อมูล

ขั้นตอนที่คนใช้งานต้องทำ และความน่าเชื่อถือของระบบครับ
