สวัสดีครับ ผม Wariddon Rattanamalee ที่ SCB ผมทำ API สำหรับธนาคาร ส่วนที่ InblackM ผมทำเครื่องมือให้พนักงานใช้ตรวจออเดอร์ครับ

ผมเริ่มเขียนระบบประกันภัยในปี 2018 จากนั้นทำงานด้านโทรคมนาคม ระบบจัดการสิทธิ์ และงานธนาคาร ผมขอเล่าตัวอย่างที่ผมลงมือทำครับ

ที่ไทยประกันภัย ผมทำ API ส่งข้อมูลกรมธรรม์ไปให้ คปภ. แบบเรียลไทม์ งานส่วนนี้รวมถึงการจัดการใบรับรองและเข้ารหัสข้อมูลด้วยครับ

ผมยังทำ TMB Tablet และระบบที่พนักงานใช้ดูแลตัวแทน คู่ค้า และรายการเดินบัญชีด้วย

ที่ กสท โทรคมนาคม ผมเขียน Java กับ Spring Boot แล้วช่วยทดสอบว่าฟีเจอร์ที่ทำตรงกับงานที่ฝ่ายธุรกิจต้องใช้

ที่ทิสโก้ ผมทำระบบจัดการสิทธิ์ด้วย Python กับ Angular อีกงานคือระบบลายมือชื่อดิจิทัล และช่วยทดสอบประสิทธิภาพด้วย LoadRunner

ที่ SCB ตำแหน่งของผมคือ วิศวกรซอฟต์แวร์ นักพัฒนาฟูลสแตก ผมทำ API ธนาคารด้วย Java และ Spring Boot ครับ

ตอนย้าย SCB Connect ผมช่วยปรับ Gateway แล้วตามแก้ปัญหาที่ทีมเจอระหว่างทดสอบ UAT

บริการที่ต่อ Redis ทำงานได้นานกว่าอายุโทเคน ผมเลยปรับการต่ออายุและการสลับพูล ให้ตอนต่อกลับใช้ข้อมูลรับรองชุดใหม่

งานรายงาน AML ผมแยกข้อความแจ้งเดือนที่ไม่มีข้อมูลออกจากกรณีส่งไม่สำเร็จ ทีมจะได้รู้ว่าต้องตามเรื่องไหน

ที่ InblackM ผมเป็นที่ปรึกษาอาวุโสด้านการพัฒนาเทคโนโลยีแบบพาร์ตไทม์ ผมทำหน้าตรวจออเดอร์และตั้งราคาด้วย React กับ Next.js

ก่อนส่งต่องาน ผมให้ระบบตรวจทั้งเจ้าของและสถานะออเดอร์ จากนั้นค่อยแก้ข้อมูลคิวกับรายการต้นทางพร้อมกัน

ผมใช้ Claude กับ Codex ช่วยไล่คำขอข้ามบริการ หรือตามจากหน้าที่พนักงานเห็นไปจนถึง worker ที่รับออเดอร์

ก่อนใช้โค้ด ผมอ่านส่วนที่แก้และรันเทสต์เอง ส่วนผู้ช่วย AI ของแอดมิน ผมตรวจแหล่งอ้างอิง และให้พนักงานดูผลค้นหาเดิมได้ด้วย

ผมจบวิทยาการคอมพิวเตอร์จากมหาวิทยาลัยบูรพา แล้วเรียนต่อบริหารธุรกิจมหาบัณฑิต ด้านการเงินและการธนาคาร ที่มหาวิทยาลัยรามคำแหง

ขอบคุณที่รับฟังครับ สไลด์กับเรซูเม่ของผมเปิดดูต่อได้ในพอร์ตครับ
