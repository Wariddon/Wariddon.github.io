ประสบการณ์ปัจจุบัน

ธนาคารไทยพาณิชย์ (SCB)

พ.ค. 2024 – ปัจจุบัน

นักพัฒนาระบบหลังบ้าน

  • พัฒนา API ธนาคารด้วย Spring Boot ร่วมย้ายระบบ SCB Connect ทดสอบ UAT และนำระบบขึ้นใช้งาน วิเคราะห์ปัญหาการทยอยออกรุ่นบน AWS EKS จากเหตุการณ์ของ Pod และค่ากำหนด Deployment
  • ปรับรุ่นบริการ Spring Boot และ Spring Cloud พร้อมปรับ Gateway ไลบรารี และกระบวนการ CI/CD สำหรับ Azure AKS
  • เชื่อม Azure Managed Redis ด้วย Entra Managed Identity รองรับการต่ออายุโทเคน การสลับพูลการเชื่อมต่อ และการใช้ข้อมูลรับรองใหม่เมื่อเชื่อมต่ออีกครั้ง
  • พัฒนาระบบส่งรายงาน AML ผ่าน Azure Blob Storage และ SMTP รองรับไฟล์แนบ ZIP การแจ้งรอบที่ไม่มีข้อมูล และการแจ้งเมื่อส่งไม่สำเร็จ
  • แก้ API ข้อมูลลูกค้าให้แยกการละเว้นที่อยู่ออกจากการขอล้างค่า รองรับยอดรายได้ขนาดใหญ่ และแก้ไขเวลาที่บันทึกสำหรับการตรวจสอบย้อนหลัง พร้อมเพิ่มชุดทดสอบ
  • พัฒนา API รับงานแบบอะซิงโครนัสสำหรับ Azure Data Factory ให้ตอบกลับด้วยรหัสงาน ตรวจคำขอซ้ำ และติดตามการสร้างไฟล์จากบันทึกการทำงานได้

InblackM

มิ.ย. 2026 – ปัจจุบัน

ที่ปรึกษาอาวุโสด้านการพัฒนาเทคโนโลยี (พาร์ตไทม์)

  • สร้างเครื่องมือตั้งราคาแพ็กเกจและตรวจออเดอร์ด้วย React และ Next.js แสดงโปรไฟล์พนักงานและผู้รับผิดชอบร่วมของออเดอร์แบบกลุ่ม
  • พัฒนาการส่งต่องานด้วยธุรกรรมฐานข้อมูล ตรวจผู้รับผิดชอบและคำขอซ้ำ กำหนดวันหมดอายุแยกรายแพ็ก และส่งรายการชำระเงิน QR เดิมให้พนักงานตรวจสอบ
  • เชื่อมระบบเข้าสู่ระบบครั้งเดียว (SSO) สำหรับพนักงานระหว่างแอป System และ Audit ตรวจสอบเซสชัน การเข้าและออกจากระบบ พร้อมทดสอบการทำงานเดิม
  • สร้างผู้ช่วย AI แบบอ่านอย่างเดียวสำหรับผู้ดูแลระบบด้วย OpenAI Responses API ให้ค้นหลักฐานฝั่งเซิร์ฟเวอร์ ตรวจรูปแบบคำตอบ และรองรับกรณีที่ตอบไม่ได้
  • ร่วมพัฒนาบริการ ERP ด้วย Go สำหรับหลายองค์กร จัดเก็บข้อมูลลับแยกตามองค์กร และตรวจพื้นที่ลงเวลาทำงาน
  • ปรับคิวรีคิวงาน PostgreSQL บนระบบจริง หลังเพิ่มดัชนี พบว่าฐานข้อมูลเลือกใช้ดัชนีใหม่ในแผนการทำงานทั้ง 18 แผนที่ทดสอบ
  • ดูแลเซิร์ฟเวอร์ Linux ที่ใช้ Nginx, PostgreSQL และ PM2 ติดตั้งแพตช์ความปลอดภัย ทดสอบกู้คืนฐานข้อมูล และตรวจความพร้อมของบริการหลังสลับรุ่น
  • ติดตั้ง Cloudflare Turnstile ที่หน้าเข้าสู่ระบบ ทดสอบว่าคำขอที่ไม่มีโทเคนหรือใช้โทเคนผิดไม่สร้างเซสชัน และวิเคราะห์อีเมล OTP ที่ส่งไม่ถึงจากเหตุการณ์ใน Cloudflare และรหัสตอบกลับ SMTP
  • พัฒนาระบบสมาชิกด้วย OpenID Connect เชื่อมโปรไฟล์ กลุ่ม และฟีดระหว่าง Rust API กับ Next.js รวมถึงพัฒนาหน้าร้านและแค็ตตาล็อกให้แพลตฟอร์มมาร์เก็ตเพลซอีกโครงการหนึ่ง
