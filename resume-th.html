  • อัปเกรด Spring Boot และ Spring Cloud พร้อมปรับ Gateway, library และ CI/CD pipeline ให้ใช้กับ Azure AKS

  • แก้ API ให้แยกได้ว่าผู้ใช้ไม่ได้ส่งที่อยู่มา หรือขอล้างที่อยู่เดิม เพิ่มชุดทดสอบสำหรับการแก้ที่อยู่ ยอดรายได้สูง และเวลาที่บันทึกไว้ตรวจสอบย้อนหลัง
  • ทำ API รับงานจาก Azure Data Factory โดยตรวจ request ซ้ำและส่ง job ID กลับทันที ทีมใช้ ID นี้ตามขั้นตอนสร้างไฟล์ใน log ได้

InblackM

มิ.ย. 2026 – ปัจจุบัน

ที่ปรึกษาอาวุโสด้านการพัฒนาเทคโนโลยี (พาร์ตไทม์)

  • สร้างเครื่องมือตั้งราคาแพ็กเกจและตรวจออเดอร์ด้วย React และ Next.js แสดงโปรไฟล์พนักงานและผู้รับผิดชอบร่วมของออเดอร์แบบกลุ่ม
  • เพิ่มการตรวจเจ้าของออเดอร์ก่อนส่งต่องาน และกันการส่งต่อซ้ำเมื่อระบบ retry กำหนดให้แพ็กที่ยังไม่ชำระหมดอายุแยกกัน โดยพนักงานยังเปิดดูรายการ QR เดิมได้
  • ทำ SSO ให้พนักงานล็อกอินครั้งเดียวแล้วใช้ได้ทั้ง System และ Audit ทดสอบทั้งตอนล็อกอิน ล็อกเอาต์ และตอนที่แต่ละแอปตรวจ session
  • ทำผู้ช่วยค้นออเดอร์แบบอ่านอย่างเดียวให้ทีมแอดมิน ระบบดึงข้อมูลฝั่งเซิร์ฟเวอร์แล้วตรวจคำตอบจาก OpenAI Responses API ถ้าคำตอบไม่ผ่าน พนักงานยังเปิดดูผลค้นหาเดิมได้
  • ร่วมพัฒนาบริการ ERP ด้วย Go สำหรับหลายองค์กร จัดเก็บข้อมูลลับแยกตามองค์กร และตรวจพื้นที่ลงเวลาทำงาน
  • เพิ่ม index ให้คิวงานใน PostgreSQL บน production แล้วตรวจ query plan ทั้ง 18 กรณี พบว่าทุกกรณีใช้ index ใหม่
  • ดูแล Linux, Nginx, PostgreSQL และ PM2 ทั้งการลงแพตช์ความปลอดภัย ทดลองกู้ฐานข้อมูลจาก backup และตรวจว่าบริการกลับมาทำงานหลังอัปเดต
  • ติดตั้ง Cloudflare Turnstile ที่หน้าล็อกอิน และทดสอบว่าคำขอที่ไม่มี token หรือส่ง token ผิดจะเปิด session ไม่ได้ อีกงานหนึ่งคือไล่สาเหตุที่อีเมล OTP ส่งไม่ถึงจากประวัติการส่งใน Cloudflare และรหัสตอบกลับ SMTP
  • ทำระบบสมาชิกด้วย OpenID Connect และเชื่อมหน้าโปรไฟล์ กลุ่ม และฟีดใน Next.js กับ API ที่เขียนด้วย Rust ส่วนงาน marketplace ผมดูแลหน้าร้านและรายการสินค้า
