ประสบการณ์ปัจจุบัน

ธนาคารไทยพาณิชย์ (SCB)

พ.ค. 2024 – ปัจจุบัน

วิศวกรซอฟต์แวร์, นักพัฒนาฟูลสแตก

  • พัฒนา API ธนาคารด้วย Spring Boot และช่วยย้าย SCB Connect ตั้งแต่ทดสอบ UAT จนถึงขั้นนำขึ้นใช้งาน เมื่อออกรุ่นบน AWS EKS แล้ว Pod ค้าง ใช้เหตุการณ์ของ Pod และค่า Deployment ไล่หาสาเหตุ
  • ปรับรุ่นบริการ Spring Boot และ Spring Cloud พร้อมปรับ Gateway ไลบรารี และกระบวนการ CI/CD สำหรับ Azure AKS
  • เชื่อมบริการกับ Azure Managed Redis ผ่าน Entra Managed Identity ปรับการต่ออายุโทเคนและการสลับพูล เพื่อให้บริการใช้ข้อมูลรับรองชุดใหม่เมื่อเชื่อมต่ออีกครั้ง
  • ทำระบบส่งรายงาน AML รายเดือน โดยอ่านไฟล์จาก Azure Blob Storage แนบ ZIP แล้วส่งอีเมลผ่าน SMTP ถ้ารอบนั้นไม่มีข้อมูลหรือส่งอีเมลไม่สำเร็จ ระบบจะแจ้งทีม
  • แก้ API ให้แยกได้ว่าผู้ใช้ไม่ได้ส่งที่อยู่มา หรือขอล้างที่อยู่เดิม เพิ่มชุดทดสอบสำหรับการแก้ที่อยู่ ยอดรายได้สูง และเวลาที่บันทึกไว้ตรวจสอบย้อนหลัง
  • ทำ API รับงานจาก Azure Data Factory ให้ส่งเลขงานกลับได้ทันทีระหว่างสร้างไฟล์ ตรวจคำขอซ้ำ และให้ทีมใช้เลขงานตามดูแต่ละขั้นใน log ได้

InblackM

มิ.ย. 2026 – ปัจจุบัน

ที่ปรึกษาอาวุโสด้านการพัฒนาเทคโนโลยี (พาร์ตไทม์)

  • สร้างเครื่องมือตั้งราคาแพ็กเกจและตรวจออเดอร์ด้วย React และ Next.js แสดงโปรไฟล์พนักงานและผู้รับผิดชอบร่วมของออเดอร์แบบกลุ่ม
  • เพิ่มการตรวจเจ้าของออเดอร์ก่อนส่งต่องาน และกันการส่งต่อซ้ำเมื่อมีการลองใหม่ กำหนดให้แพ็กที่ยังไม่ชำระหมดอายุแยกกัน โดยพนักงานยังเปิดดูรายการ QR เดิมได้
  • เชื่อมบัญชีพนักงานของแอป System และ Audit ให้เข้าสู่ระบบครั้งเดียว ทดสอบการเข้าใช้งาน การออกจากระบบ และการตรวจเซสชันระหว่างสองแอป
  • ทำผู้ช่วยค้นออเดอร์แบบอ่านอย่างเดียวให้ทีมแอดมิน ระบบดึงข้อมูลฝั่งเซิร์ฟเวอร์แล้วตรวจคำตอบจาก OpenAI Responses API ถ้าคำตอบไม่ผ่าน พนักงานยังเปิดดูผลค้นหาเดิมได้
  • ร่วมพัฒนาบริการ ERP ด้วย Go สำหรับหลายองค์กร จัดเก็บข้อมูลลับแยกตามองค์กร และตรวจพื้นที่ลงเวลาทำงาน
  • เพิ่มดัชนีให้คิวงาน PostgreSQL บนระบบจริง เมื่อตรวจหลังปรับ ฐานข้อมูลเลือกใช้ดัชนีใหม่ครบทั้ง 18 แผนที่ทดสอบ
  • ดูแล Linux, Nginx, PostgreSQL และ PM2 ทั้งการลงแพตช์ความปลอดภัย ทดลองกู้ฐานข้อมูลจากสำเนาสำรอง และตรวจว่าบริการกลับมาทำงานหลังเปลี่ยนรุ่น
  • ติดตั้ง Cloudflare Turnstile ที่หน้าล็อกอิน และทดสอบว่าคำขอที่ไม่มีโทเคนหรือใช้โทเคนผิดเปิดเซสชันไม่ได้ อีกงานหนึ่งคือไล่สาเหตุที่อีเมล OTP ส่งไม่ถึงจากประวัติการส่งใน Cloudflare และรหัสตอบกลับ SMTP
  • ทำระบบสมาชิกด้วย OpenID Connect และเชื่อมหน้าโปรไฟล์ กลุ่ม และฟีดใน Next.js กับ API ที่เขียนด้วย Rust ส่วนงานมาร์เก็ตเพลซดูแลฟีเจอร์หน้าร้านและแค็ตตาล็อกสินค้า
